# Анализ результатов A/B-теста маркетинговой механики в розничном бизнесе.

Исследование направлено на оценку влияния push-уведомлений на конверсию в покупку и средний чек по сравнению с рекламными баннерами в мобильном приложении.

## Бизнес-задача

Маркетинговая команда тестировала новую механику коммуникации с клиентами — push-уведомления вместо баннеров в мобильном приложении.

Перед масштабированием новой механики необходимо определить:

* изменяется ли конверсия клиентов в покупку;
* изменяется ли средний чек;
* одинаково ли работает механика в разных городах и торговых точках;
* какой потенциальный финансовый эффект может дать переход на новую механику.

В рамках эксперимента клиенты были случайным образом разделены на две группы:

* **Контрольная группа** — рекламные сообщения в формате баннера;
* **Тестовая группа** — push-уведомления.

---

## Цель исследования

Оценить эффективность новой маркетинговой механики и определить целесообразность её масштабирования.

### Целевые метрики

**Конверсия в покупку**

Доля клиентов, совершивших хотя бы одну покупку после получения рекламного воздействия.

**Средний чек**

Средняя сумма платежа клиента.

---

## Данные

В исследовании используются три таблицы:

### Данные

Информация о покупках:

* `id_order` — идентификатор покупки;
* `id_client` — идентификатор клиента;
* `amt_payment` — сумма платежа;
* `dtime_pay` — дата и время оплаты.

### Clients

Информация о клиентах и параметрах эксперимента:

* `id_client` — идентификатор клиента;
* `dtime_ad` — дата и время рекламного воздействия;
* `nflag_test` — группа эксперимента;
* `id_trading_point` — торговая точка клиента.

### Region_dict

Справочник торговых точек:

* `id_trading_point` — идентификатор торговой точки;
* `city` — город.

## Подготовка данных

В Python выполнены:

* проверка структуры таблиц;
* анализ пропущенных значений;
* проверка дубликатов;
* проверка распределения клиентов между экспериментальными группами;
* удаление записей с пропущенными значениями;
* агрегация нескольких платежей одного клиента;
* объединение клиентских и транзакционных данных;
* добавление информации о городе;
* формирование бинарного признака покупки;
* исключение торговых точек, в которых невозможно корректно сравнить тестовую и контрольную группы.

После подготовки данные использовались для дальнейшего статистического анализа.

## Статистический анализ

Для оценки результатов эксперимента использовались:

* **t-test Стьюдента** — сравнение средних платежей между группами;
* **t-test для бинарной метрики** — сравнение конверсии в покупку;
* **критерий Манна — Уитни** — дополнительная проверка различий распределений;
* уровень статистической значимости `α = 0.05`.

Для каждой торговой точки рассчитывались:

* количество наблюдений в тестовой и контрольной группах;
* средний платеж;
* разница средних платежей;
* стандартное отклонение;
* статистика t-критерия;
* `p-value`;
* итоговый статус эксперимента.

---

## Сегментация

Результаты дополнительно анализировались на уровне городов.

Отдельно рассматривались:

* Москва;
* Санкт-Петербург;
* остальные города.

Для каждой торговой точки формировался один из трёх результатов:

| Результат           | Условие                                      |
| ------------------- | -------------------------------------------- |
| Положительный исход | `diff > 0` и `p-value < 0.05`                |
| Отрицательный исход | `diff < 0` и `p-value < 0.05`                |
| Нейтральный исход   | статистически значимой разницы не обнаружено |

## Финальный бизнес-инструмент

На основе результатов Python-анализа сформирован Excel-калькулятор.

Калькулятор позволяет моделировать потенциальный финансовый эффект от перехода с баннеров на push-уведомления.

### Входные параметры

* `N` — количество клиентов, для которых моделируется внедрение новой механики;
* `MDE` — минимально значимая для бизнеса разница в среднем чеке.

### Ключевые расчёты

Для положительных результатов рассчитывается потенциальный прирост выручки.

Для отрицательных результатов рассчитывается потенциальное падение выручки.

Для нейтральных результатов рассчитывается необходимое количество наблюдений для обнаружения эффекта заданного размера `MDE`.

### Итоговые показатели

* потенциальный прирост выручки;
* потенциальное падение выручки;
* баланс финансового эффекта;
* необходимое количество дополнительных наблюдений.

Таким образом, результат A/B-теста переводится из статистических показателей в понятный для бизнеса финансовый эффект.

## Результаты

Основной результат исследования — классификация торговых точек по трём типам исхода:

* положительный;
* отрицательный;
* нейтральный.

На основании сегментации можно определить, где новая маркетинговая механика показывает статистически значимый положительный или отрицательный эффект, а где имеющихся данных недостаточно для принятия решения.

Детальные результаты и расчёты доступны в:

## Business Impact

Основная задача анализа — не только определить наличие статистически значимой разницы между группами, но и оценить последствия изменения маркетинговой механики для бизнеса.

Excel-калькулятор позволяет сопоставить потенциальный прирост и падение выручки и использовать результаты A/B-теста как основу для решения о масштабировании push-уведомлений.
